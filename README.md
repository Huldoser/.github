# .github

Default community health files for Huldoser's repositories. GitHub shows each file here in every repository that has
no file of the same kind; a repository with its own `.github/ISSUE_TEMPLATE` folder gets none of the issue forms.

- `CODE_OF_CONDUCT.md`: the Contributor Covenant 3.0, edited for a project with one maintainer. It keeps its licence,
  CC BY-SA 4.0, as its Attribution section says.
- `SECURITY.md`: how to report a vulnerability privately.
- `CONTRIBUTING.md`: the rules for pull requests.
- `.github/pull_request_template.md` and `.github/ISSUE_TEMPLATE/`: the pull request template and the bug and feature
  forms.
- `.github/FUNDING.yml`: the links behind the sponsor button.
