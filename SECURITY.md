# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately with **Report a vulnerability** on this repository's
**Security and quality** tab
([GitHub's guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
You'll get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless
you'd rather stay anonymous.
